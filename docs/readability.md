# 面板字体与可读性

本轮检查发现：多个面板使用 8–11px 固定字号；styles.css 的后置主题再次覆盖文字颜色，辅助文字最低为 #54545c；部分输入提示依赖浏览器默认灰色。

## 共享规范

字体大小集中在 renderer/styles.css 的 CSS 变量中。中文沿用系统字体与 Microsoft YaHei / PingFang SC 回退，代码和时间沿用等宽字体。

| 用途 | 变量 | 字号 |
| --- | --- | --- |
| 数量、日期、提示 | --fs-micro / --fs-caption | 12px |
| 辅助内容 | --fs-small / --fs-code | 13px |
| 常用控件 | --fs-ui | 14px |
| 正文 | --fs-body | 15px |
| 大正文 | --fs-body-lg | 16px |
| 标题层级 | --fs-heading-3 / 2 / 1 | 17 / 19 / 21px |

正文颜色 #f7f7f8，次要文字 #d0d0d6，说明文字 #b8b8c2，弱提示 #a6a6b2。弱提示仍应能直接阅读；禁用控件可另用透明度表现不可用。状态色与标题层级保留，避免所有信息同样醒目。

## 面板调整

- 首页：组件标签、随笔记、常用指令说明和番茄钟状态。
- 待办：时间筛选、任务文字、截止日期、输入提示和编辑器。
- 笔记：分类树、数量、列表摘要、日期、工具栏和正文。
- 链接：搜索、网址、分组标题、数量和加载按钮。
- 录音：录音列表、时间、转写正文和整理动作。
- 密钥：字段标签、输入提示、说明和列表。
- 设置与 AI：导航、厂商与模型状态、表单、诊断和结果预览。
- 启动器：分组、结果、副标题、快捷键提示；顶栏搜索按钮加宽并禁止换行。

固定小字号接入共享变量，后续改动应复用这些变量，避免重新引入 8–11px 文字。图标、装饰与大号时钟无需统一为正文字号。

## 验证范围

使用 Windows Electron 测试场景检查交互与内容溢出，并检查标准窗口截图；测试覆盖 720px 内容宽度与 300px 内容高度约束，但不等同于物理显示器 DPI 或 macOS 验收。截图保存在 dist.noindex/，不提交 Git。真实用户的阅读舒适度仍需在日常屏幕上确认。
