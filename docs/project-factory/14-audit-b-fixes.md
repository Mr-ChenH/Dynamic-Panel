# B-001–B-007 修复记录

对应 13-current-gap-audit.md。本轮修复审计问题，不将剩余产品需求和平台验收全部关闭。

| 问题 | 当前处理 |
| --- | --- |
| B-001 文件类型绕过 | 普通文件打开采用明确的数据文件白名单，拒绝 CPL/PIF/SCT/未知扩展等；目录仍可打开。主进程使用校验返回的真实路径执行，不再打开原始别名路径。系统文件关联仍由用户的操作系统控制，这不是执行沙箱 |
| B-002 URL 身份混用 | 直接网址以 URL 解析后的完整 href 生成独立 ID，解析失败不生成结果；不同 URL 不再共享 builtin:url 配置 |
| B-003 临时收藏无法恢复 | 选择限制不支持持久恢复的结果操作：临时路径、直接网址和动态扩展结果不提供收藏/别名，不参与持久 usage 排名，也忽略旧别名。保存的链接、工作区资源、应用和扩展命令入口仍支持配置。旧失效记录不自动删除，可在管理中移除 |
| B-004 长文本负分 | 标题前缀和子序列长度扣分有上限，命中不会因长度变成负分，精确别名仍优先 |
| B-005 保存失败误报 | 保存失败时保留错误和编辑上下文，不关闭动作面板或显示成功；多字段移除保留旧值并在失败时尝试回滚，若回滚也失败则明确提示部分变更；动作已经执行但 usage 保存失败时明确区分二者 |
| B-006 过期偏好抢选中 | 搜索期间保留偏好，最终批次完成后将偏好更新为实际选中项；下一轮从最终选中项继续，失败响应也结束 pending 状态 |
| B-007 宿主失败未记录 | 动态执行等宿主动作完成后才记成功；声明式宿主动作同样记录结果。导航发放一次性结果 token，先记录 pending-navigation，收到 renderer 校验/导航结果后完成诊断；未回报不会被记为成功 |

## 验证

- Node：CPL/PIF/SCT/未知类型拒绝，7000 字符前缀/子序列命中，精确别名优先；临时结果动作限制与旧别名不参与匹配。
- Node：process 与 declarative 宿主失败写入诊断、重建 service 后恢复；导航 pending 到失败转换、重复 token 拒绝。
- 生产 Electron：URL 身份区分、临时结果无收藏入口、A 被过滤回退 B 后保持 B；注入 LocalStorage 写入异常，验证错误不被成功提示覆盖；注入多字段移除失败，验证别名恢复和撤回提示。
- 完整 npm test：138 项 Node case，137 通过、1 项 POSIX SIGTERM 场景在 Windows 跳过；3 组 Electron 场景及语法检查通过；git diff --check 通过。
