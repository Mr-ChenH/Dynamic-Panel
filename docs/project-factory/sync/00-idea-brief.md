# Sync Idea Brief

## Summary

为 Dynamic Panel 增加一个可自托管的多账号同步服务。每个账号可以创建和管理多个相互隔离的同步空间；账号用户在空间内添加客户端时，由服务端为该客户端生成唯一 Key。桌面客户端配置服务端 URL 和自己的客户端 Key 后，只与同一空间内的其他客户端同步用户选择的数据，服务端可据此可靠标记每条变更的来源客户端。服务端还执行可验证、可恢复的定时备份。

本阶段只定义产品边界和需求，不选择最终服务端框架、数据库或对象存储，也不修改运行代码。

## Target Users

- 在 macOS 与 Windows 多台个人设备上使用 Dynamic Panel 的账号用户。
- 需要在同一账号下维护工作、个人或项目等多个独立空间的用户。
- 希望自托管多账号数据、由服务端隔离不同账号与空间的用户。
- 负责部署、账号治理、升级、备份和恢复同步服务的服务器管理员。

## Goals

- 一个服务实例支持多个账号，每个账号支持多个相互隔离的同步空间。
- 同一空间中的不同客户端对待办、笔记、链接及其附件进行离线优先的近实时同步。
- 空间之间不传播数据、游标、对象存在性、用量、结构限制状态或客户端信息。
- 支持用户明确启用剪贴板和截图等敏感数据的同步；音频录音与屏幕录制延后。
- 同步配置中可跨设备的部分，同时排除路径、快捷键、凭据等设备专属数据。
- 在并发编辑、断网、重复请求和设备长期离线后仍不静默丢失数据。
- 提供每客户端 Key 的生成、吊销、轮换、安装绑定和来源审计能力。
- 提供独立于实时同步的定时备份、校验和恢复流程。

## Must-Have Features

- 服务端支持账号生命周期和账号级隔离；MVP 账号只由服务器管理员创建。
- 账号使用服务端本地用户名/密码认证，并通过精简 Web 控制台管理自身资源。
- 账号可以创建、重命名、查看、停用和删除多个同步空间；同一账号内空间名称唯一，每个账号最多 10 个活动空间。
- 账号在空间中添加具名客户端时，服务端为每个客户端独立生成高强度随机 Key；每个空间最多 10 个活动客户端。
- 客户端 Key 只能代表对应空间中的对应客户端，不能管理账号、访问其他空间或冒充其他客户端。
- 桌面客户端配置服务端 URL、客户端 Key 和同步分类；数据来源由服务端根据 Key 绑定的客户端身份确定。
- 服务端管理员可通过管理 CLI 执行账号生命周期、全局结构限制、备份和恢复操作。
- 首次连接预检、客户端 Key 安装绑定、首次同步选择和进度反馈。
- 增量 push/pull、实时变更通知、轮询降级、离线队列和断点续传。
- 稳定实体 ID、版本游标、幂等操作、删除墓碑和冲突保留。
- 元数据与附件分离；附件具备摘要校验、去重和完整性检查。
- 服务端定时备份、保留策略、备份状态、恢复预演和正式恢复。
- 明确的数据分类、隐私默认值、容量限制和错误处理。

## Constraints

- 不同账号以及同一账号下的不同空间必须在授权、记录、对象、游标、客户端、用量、结构限制、审计和恢复操作上保持隔离。
- 保持现有 IPC 名称、preload API、LocalStorage 键、工作区 schema 和用户行为兼容；后续实现必须通过适配层迁移，不能直接改变旧数据含义。
- 当前 `workspace.json` 是全量 LocalStorage 快照，不是可直接复用的双向同步协议。
- 现有附件分布在 `recordings/`、`clipboard-images/`、`note-images/` 和 `captures/`；同步不能假定所有数据都在 LocalStorage。
- `safeStorage` 密文、客户端 Key、第三方 API Key、本机路径、全局快捷键和设备窗口偏好不能原样跨设备复制。
- 剪贴板、截图和 AI 会话属于高敏感数据，必须由用户显式启用；录音与录屏不进入 MVP 同步范围。
- 服务端 URL 在生产环境必须使用 HTTPS；只允许在明确的本机开发模式使用回环 HTTP。
- 桌面端继续支持离线使用；同步失败不得阻塞本地保存。

## Assumptions

- MVP 是多账号模型；账号只由服务器管理员创建，使用本地用户名/密码认证。
- 剪贴板作为单一同步分类，文字历史、收藏和图片附件使用同一个开关，不拆分。
- 不设置对象总字节、图片数量和单图大小的业务配额；请求、分块、并发和存储失败仍必须受技术安全边界保护。
- 删除墓碑和未解决冲突保留 30 天；备份采用 7 个每日、4 个每周、12 个每月恢复点。
- 默认跨设备设置仅包括主题、功能显隐和默认页，其他设置保持本地，除非后续另行确认。
- 本地账号首版不支持 MFA，只提供高强度密码、会话撤销和管理员重置。
- 每个账号可以拥有最多 10 个活动空间，每个空间最多 10 个活动客户端；同一账号内空间名称唯一。
- 账号用户通过精简 Web 控制台管理空间、客户端、客户端 Key、用量和审计；服务端管理员使用管理 CLI。
- 一个空间只属于一个账号；MVP 不包含跨账号共享空间、团队成员和细粒度成员权限。
- 账号认证只用于管理本账号及其空间；账号用户先在空间中添加客户端，桌面端再通过该客户端唯一 Key 连接，不保存账号密码。
- 同一空间的不同客户端必须使用不同 Key；客户端 Key 首次连接时绑定该安装生成的稳定安装 ID，之后不得用于另一安装。
- 服务端不得信任客户端自报的来源 ID，必须从认证 Key 推导来源客户端；重装或迁移需先在 Web 控制台重置绑定并轮换 Key。
- 每个本地工作区最多绑定一个远端客户端身份；切换空间或客户端 Key 时不得混用 outbox、游标或本地附件映射。
- 客户端 Key 是访问凭据，不等同于端到端加密密钥；MVP 由服务端处理明文业务数据，并依赖 TLS 与服务端静态加密保护。
- MVP 媒体范围只包括笔记图片、剪贴板图片和截图；音频录音与屏幕录制延后。
- 生产备份以 S3 兼容对象存储为主要目标；本地目录只用于开发或挂载到独立备份介质。
- 首次同步默认安全合并，同时允许建立恢复点并二次确认后的高级整端覆盖。
- 同步范围按数据类别配置，而不是简单上传整个用户目录。
- 服务端可能部署在公网，也可能部署在用户自己的局域网或私有云中。
- “实时”表示在线设备通常在数秒内看到变化，不承诺强一致或协同编辑器级别的逐字符同步。
- 备份目标存储应与在线数据故障域分离；只在同一磁盘复制文件不视为合格备份。

## Confirmed MVP Limits

- 每个账号最多 10 个活动空间。
- 每个空间最多 10 个活动客户端。
- 对象总字节、图片数量和单图大小暂不设置业务配额。
- 剪贴板使用一个开关，同时控制文字、收藏和图片。
- 删除/冲突保留 30 天；备份保留 7 日、4 周、12 月。
- 默认同步设置仅为主题、功能显隐和默认页。
- 首版不支持 MFA。
