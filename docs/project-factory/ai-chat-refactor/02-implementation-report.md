# AI 临时对话第一阶段实施报告

## 已交付

- 首页 AI 入口显示当前内容模型，并明确只发送用户输入。
- 对话顶栏显示临时会话、厂商、模型，并提供返回、新建对话和 AI 设置入口。
- 空态提供规划今天、整理想法、解释问题和拆解行动四个起始建议；建议只填入输入框，不自动调用模型。
- 输入框固定在底部并自动增高；Enter 发送、Shift + Enter 换行；生成期间仍可编辑下一条草稿，发送按钮原位切换为停止。
- 用户问题提交后立即固定在消息流中。停止保留已收到的部分回复，失败保留问题和错误状态，两者都提供重试，但不进入后续成功上下文。
- 重试绑定该轮的有界上下文，旧答案标记为上一版本，新答案标记为新版本，不静默覆盖。
- 完整回复支持安全 Markdown 标题、段落、强调、列表、引用、表格、链接和代码块；代码块可单独复制。
- 完整回复提供复制、重新生成和保存为笔记；保存后可冲突安全撤销。
- 模型链接和现有通用外链 IPC 统一经过公网 HTTP/HTTPS、凭据、本机、`.local`、私网和保留地址校验。
- 继续保留统一 AI 网关、最多两个活动请求、严格 SSE 完整性、64 KiB 有效回复、12,000 字符总输入和最近六轮成功上下文。

## 安全边界

`renderer/markdown.js` 不接收或写入模型 HTML。渲染节点通过 DOM API 和 `textContent` 创建；唯一的 `innerHTML` 用于应用内固定 SVG 图标。流式阶段只显示纯文本，收到完整成功结果后才执行 Markdown 分块渲染。

对话默认仅存在于当前窗口内存，不读取笔记、录音、待办、链接、剪贴板或当前窗口，不联网搜索，不调用工具，不自动保存任何内容。用户点击“保存为笔记”后才写入现有笔记库。

## 后续范围

本阶段未加入多会话持久历史、搜索、附件、应用内资料上下文、联网引用、工具调用或任务执行。后续若添加资料上下文，必须由用户逐条选择并在输入区显示可移除标签；若添加搜索，必须展示真实可核验来源，不复用模型自行生成的引用。
