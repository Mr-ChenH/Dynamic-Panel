# 启动器实现与验收记录

日期：2026-09-11。状态：本地开发实现，未打包、未发布。**完整性复查结论：尚未满足全部 MVP 需求，不能将本报告中的核心实现视为完整验收。** 逐项需求状态、现有缺陷与覆盖缺口见 [09-completeness-audit.md](09-completeness-audit.md)。以下保留初轮实现记录，涉及完整性与验收判断以复查结果为准。

## 已实现

- 顶栏搜索、设置入口和独立全局快捷键；注册新快捷键成功后才释放旧快捷键；留空禁用。
- 复用主窗口的新 launcher 原生模式；Windows 保持固定画布，仅将输入形状切换为启动器矩形；macOS 使用贴顶紧凑窗口。
- 自动聚焦、上下/Home/End 选择、Enter 执行、IME 保护、焦点循环、分层 Escape、动作面板。
- 应用、笔记、待办、链接、旧常用指令和可选剪贴板文字来源；笔记按 ID 定位，待办切换全部视图并滚动定位；新建笔记与待办入口。
- 收藏、唯一别名、模糊子序列搜索、使用记录；空查询最多 12 项、非空查询最多 50 项。
- 本地扩展目录暂存、manifest 校验、用户确认、安装、启用/禁用、卸载和诊断复制。
- 声明式复制/网址动作；显式命令作用域动态查询；查询/执行 JSON Lines；取消、超时、输出上限和进程退出回收。
- `examples/launcher/local-tools` 展示声明式复制与动态大写转换；扩展作者文档独立提供。
- electron-builder files 纳入 launcher 模块；没有运行打包。

## 实现取舍

| 设计项 | 本轮实现及原因 |
| --- | --- |
| utilityProcess + JSON Lines stdin | 使用 Electron `ELECTRON_RUN_AS_NODE` 子进程；utilityProcess 不支持可写 stdin。每个请求独立进程，避免跨查询内存依赖 |
| 查询 800ms | 默认 1500ms，包含本机进程冷启动；执行 5000ms；这些是超时配置，不是实测性能指标 |
| 全局动态查询 | 只在输入命令标题/ID 加空格后执行，普通输入不广播给所有扩展 |
| 安装状态随工作区迁移 | 安装与启用留在 userData/launcher，迁移后需重新安装；避免打开外来工作区即执行代码 |
| 快捷键随工作区迁移 | 快捷键和来源保存在 userData/launcher-settings.json，匹配本机快捷键占用；收藏/别名/usage 使用既定 LocalStorage 键 |
| manifest 权限 | 限制宿主动作；不是完整系统沙箱。Node 进程可自行访问本机文件/网络，安装确认明确说明 |
| 任意路径/通用 shell 动作 | 首版宿主不开放；应用仅从扫描缓存启动，网址经公开地址校验 |
| 进程扩展依赖 | 安装时不复制 node_modules，作者预打包依赖；不运行 npm/install 脚本 |

## 未验证与后续范围

- 当前执行环境是 Windows；未进行 macOS 实机、Windows 10 实机或物理多屏人工验收。没有声称这些硬件场景通过。
- 首屏 150ms/本地搜索 100ms 等设计指标尚未建立基准测量，不能视为已达标。
- Windows 应用索引覆盖开始菜单/桌面 `.lnk`，不保证全部 MSIX/AUMID 程序；macOS 应用目录扫描实现尚待实机验证。
- 不提供 zip 导入、扩展更新/回滚、在线商店、签名分发、OS 沙箱、强制终止扩展自行派生的所有后代进程。
- 不提供全盘文件搜索、完整拼音、多页扩展 UI、扩展密钥 API、历史错误列表、最近运行时间、系统应用图标和完整来源分组。
- 窗口关闭恢复工作台/折叠状态；跨应用强制恢复 OS 焦点不作保证，遵守平台能力边界。
