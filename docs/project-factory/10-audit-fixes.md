# 审计问题修复记录

对应 `09-completeness-audit.md` 的 A-001–A-006。本轮处理已实现功能的缺陷，不将其他 MVP 缺项标记为完成。

| 问题 | 修复 |
| --- | --- |
| A-001 超时回收 | POSIX 使用独立进程组，先 SIGTERM，250ms 后升级 SIGKILL；Windows 使用 taskkill /T /F。清理有 1500ms 最终上限，失败返回 extension_cleanup_failed；直接子进程退出后才结算请求。此机制不是 OS 沙箱，逃离进程组的后代不作安全隔离保证 |
| A-002 运行中卸载/并发 | 跟踪活动 host Promise，cancel 等待回收；安装/启停/卸载/查询执行共用串行队列；新查询取消旧查询，取消也使排队查询失效。卸载先持久化禁用、等待退出再删除目录，删除失败仍保留禁用记录 |
| A-003 远端选择/慢结果 | 独立保存偏好选项 ID，空的中间批次不清除偏好；应用与声明式结果通过带 requestId 的 partial 事件先返回；过期批次被丢弃 |
| A-004 失败导航 | 先校验目标/功能开关，再完成导航，最后写 usage 和关闭；失败保留启动器与可见错误，不记成功 |
| A-005 定位 | 已完成待办自动展开对应完成区；链接保留 ID，打开来源页时展开分组、滚动定位；已删除笔记/待办/链接明确拒绝 |
| A-006 状态竞争 | 过渡与执行时保留待关闭意图；管理期间禁用搜索输入及动态查询；管理异步结果使用版本校验；按钮异步错误可见，重复动作受 busy/disabled 保护；安装清理异常仍释放主进程管理锁 |
