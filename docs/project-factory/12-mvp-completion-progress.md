# 启动器 MVP 补齐进展

基于 09 完成度审计及 10–11 修复记录。本轮继续实现未完成的功能，未提交、打包或发布。

## 本轮交付

- 本机绝对路径查询：文件/目录结果有稳定 ID；执行时再次校验真实路径、文件类型和存在性，拒绝网络/设备路径、Windows ADS、脚本/可执行文件和 macOS app 包绕过；应用仍通过扫描缓存启动。
- 结果按收藏、最近使用和来源分组，键盘顺序与显示顺序一致；扩展来源显示名称/声明权限/本地代码标记。
- 统一结果描述包含 source/risk/actions/confirmation；右键可打开动作面板；直接输入 URL 不再误提供无目标的来源定位。
- 应用图标由主进程基于已扫描 target 获取，主进程和 renderer 均使用有界缓存。
- 设置集中展示收藏和别名，允许编辑唯一别名与移除失效记录；全角、半角和大小写统一比较。
- 扩展安装确认和管理页显示入口；诊断持久化最近运行时间与 20 条状态/耗时记录，包含查询和执行失败，不保存查询内容或输出。
- 扩展新增 readFiles 授权的 open-path，以及有限 tab/id 的 navigate 动作；执行仍经主进程/工作区目标校验。
- 请求显式携带 extensionId，context.storagePath 提供每扩展专属本机持久目录。专属路径是数据组织方式，不是 OS 隔离。
- 查询默认超时统一为 800ms，可设置为 300–5000ms；执行仍为 5000ms。内部 runner 实现 ready 握手，Node 启动上限独立为 1500ms，运行时就绪后再计查询/执行时间；取消尽力投递 cancel 帧后继续强制回收。
- launcher 从展开工作台进入时也按鼠标所在屏定位。
- 开关动画为 140/100ms，保留水平居中 transform，并尊重 prefers-reduced-motion。
- 解析与工作区派生结果缓存按原始存储值失效，排序仍即时读取收藏/usage。收藏、别名和 usage 增加结构和数量过滤。
- 修复测试补齐时发现的两个问题：动态命令入口被 running 状态挡住搜索；Electron 异步剪贴板写入未等待完成。
- 截图验收发现的工作区子元素透出已修复，新增所有 panel 子元素计算样式断言。

## 新增验收证据

- 文件/目录/缺失路径/脚本/设备路径/ADS 边界测试。
- 扩展 open-path 权限和 navigate 目标白名单测试。
- 扩展真实目录 junction/symlink 与超过 20MiB 包拒绝测试。
- 扩展运行历史重启恢复及不保存 query 正文测试。
- 通过目录夹具验证 macOS .app 和 Windows .lnk 发现逻辑与稳定 ID；不等于两平台 OS 启动实测。
- 生产 Electron 通过真实 preload 查询/执行 Node 模式扩展，并检查系统剪贴板内容。
- 工作区快照恢复收藏与别名；右键动作、NFKC 别名冲突、管理页历史展示和超时设置测试。
- 界面截图 `dist.noindex/launcher-review.png` 为本地验收产物，不提交。

最终检查：134 项 Node case，133 通过、1 项 POSIX SIGTERM 场景在 Windows 跳过；3 组 Electron 场景、语法检查和 git diff --check 通过。

## 性能样本

Windows / Node 22.19.0，非发布构建。

- `node scripts/benchmark-launcher.js`：1,000 条数据，200 次纯领域搜索；首轮约 7.57ms，P50 2.30ms，P95 3.33ms。
- 生产 Electron 本地输入事件至下一 animation frame：1,000 条笔记，20 次采样；一次运行 P50 17.4ms，P95 22.7ms。
- 以上不含 OS 全局快捷键响应、冷应用扫描或远端扩展延时，不宣称端到端性能达标。

## 仍未关闭的验收与设计项

1. macOS/Windows 10 和物理多屏上的快捷键占用、失焦、跨应用焦点恢复及 POSIX 拒绝终止测试，需要相应系统/硬件验证。
2. OS 级扩展访问限制尚未实现；延续此前明确采用的“可信本地代码”模式。若以原 FR-034 的禁止任意读写作为硬验收，仍未满足，不能用专属 storagePath 代替隔离。
3. 扩展包/授权/快捷键仍在本机，迁移工作区不会自动执行外来扩展；这遵循既有本机安装决策，与最初 FR-038 的迁移设想存在差异。
4. 完整端到端性能门禁、真实全局快捷键和跨应用焦点自动化尚未完成。
5. 原本可选/后置的商店、zip、全盘索引、MSIX 完整索引、拼音等继续后置。

所以当前不能把 14 个 TASK 或 38 个 FR 全部标成完成；本记录只关闭已有实现与证据支持的子项。
