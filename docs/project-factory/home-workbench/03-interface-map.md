# 界面与交互

- 首页工作台：默认入口；今日重点→具体待办；继续工作→指定笔记（清空旧筛选）；收集→独立笔记；录音→录音页。
- 天气卡：搜索城市→选择候选→查看；刷新复用15分钟缓存；清除城市停止后续刷新。空、查询中、失败、旧缓存均有文案。
- 音乐卡：显示当前来源、曲目与文件/主机信息；提供只读进度、上一首、播放暂停和下一首。音乐库为空时进入设置页添加来源。
- 设置 / 音乐：本地音乐与网络音乐分段切换；本地侧可批量选择文件或递归导入文件夹，网络侧填写 HTTPS 音频直链和可选名称；当前来源列表支持直接播放与移除。
- AI 对话：打开→选择起始建议或输入→可选“添加参考资料”→按笔记/录音/待办/链接/剪贴板筛选或搜索→选择最多 3 份→从输入区标签复核/移除→发送→增量显示→复制 / 重试 / 保存笔记；用户消息显示实际来源。停止保留部分回复并标记不计入上下文；失败保留问题和原位重试；重试复用发送时冻结的资料快照。默认对话为临时状态；点击保存先打开范围说明，再确认保存到当前工作区。历史抽屉支持搜索、切换、行内重命名、二次确认删除和新建临时对话；刷新后重建消息与操作。完整长回答可从回复操作打开独立阅读工作台，通过标题大纲定位，复制全文/选区，保存笔记或撤销，并将合规的全文/选区送入待办候选预览；返回后恢复聊天滚动位置和草稿。新建对话取消活动请求并丢弃未保存的临时历史与待发送资料；返回首页时取消活动请求。

新表单和按钮使用原生可聚焦控件，所有输入有标签；资料类型分段支持左右方向键、Home 和 End；状态区域使用 role=status，流式正文不逐字广播。Enter 发送、Shift+Enter 换行，输入法合成时不触发。
