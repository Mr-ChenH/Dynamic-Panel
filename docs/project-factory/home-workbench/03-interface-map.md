# 界面与交互

- 首页工作台：默认入口；今日重点→具体待办；继续工作→指定笔记（清空旧筛选）；收集→独立笔记；录音→录音页。
- 天气卡：搜索城市→选择候选→查看；刷新复用15分钟缓存；清除城市停止后续刷新。空、查询中、失败、旧缓存均有文案。
- 音乐卡：显示当前媒体歌曲与歌手；依据能力启用上一首/播放暂停/下一首。无会话显示启动播放器提示。
- AI 对话：打开→输入→发送→增量显示→复制；停止丢弃未完成回复，输入保留；清空取消请求并丢弃内存历史；返回首页时取消活动请求。

新表单和按钮使用原生可聚焦控件，所有输入有标签；状态区域使用role=status，流式正文不逐字广播。Ctrl/Cmd+Enter发送，输入法合成时不触发。
