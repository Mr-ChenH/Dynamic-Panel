# 首页工作台 MVP 需求

用户授权：新增音乐控制、天气、AI 对话，并按前轮调研改造首页。已有 Electron 双平台架构、持久化数据与可读性规范沿用。未经授权不打包、发布或推送。

## 功能与验收
- FR-001 / AC-001 今日重点：显示今日及逾期未完成任务，最多 3 条；可进入待办定位操作。首版不新增任务计划日期，明确按截止日期筛选。
- FR-002 / AC-002 继续工作：显示最多 5 篇最近编辑笔记，包含分类、时间，一键打开指定笔记。跨文件/项目恢复列入后续。
- FR-003 / AC-003 快速收集：输入后主动保存为独立笔记；保存成功才清空，失败保留草稿。提供录音入口。
- FR-004 / AC-004 天气：手动搜索/选择城市；首页概况突出当前温度、天气、当天高低温、体感、未来 6 小时最高降雨概率、湿度和风；详情页展示未来 12 小时温度/天气/降雨概率和 7 天趋势，并补充降水量与日落。不申请定位；请求失败显示错误或标记缓存；可切换或清除位置；详情页持续展示 Open-Meteo 来源。免费接口仅适用于非商业使用，商业分发须换商用方案。
- FR-005 / AC-005 音乐：独立于旧汽水音乐组件和系统媒体播放器，由应用内 `<audio>` 播放。设置页可切换本地/网络来源；本地通过系统文件选择器导入，网络仅保存公开 HTTPS 音频直链。支持 MP3、M4A、AAC、WAV、OGG、Opus、FLAC 和 WebM，音乐库最多 200 首，单首最多 128 MB。首页显示来源、曲名、文件名或主机、播放状态及只读进度，并提供上一首、播放/暂停、下一首和自动续播；设置页提供 0–100 音量并在本机记忆。
- FR-006 / AC-006 AI 对话：用户主动发送，支持有限多轮上下文、取消、清空、复制回复；复用内容厂商默认模型与统一安全网关。未完成/失败响应不能作为成功回复保留。默认仅会话内存，不自动读取工作区或调用工具，不自动保存笔记/任务。
- FR-007 / AC-007 首页仅显示新工作台，不提供旧组件或“经典工具”入口；迁移不主动清理旧显隐偏好、排列、尺寸和速记数据。

## 非功能需求
辅助字不低于12px，正文15px；控件键盘可达；响应式内容独立滚动；网络只由主进程发起；天气端点固定、输入有界、超时、响应上限。网络音频拒绝凭据、localhost、`.local`、私网 DNS、重定向、非音频响应和超限内容，下载绑定已验证公网 IP。播放器不使用首页轮询，切换/删除来源及页面卸载时释放 Blob URL。AI保持全局并发、取消、响应限制、配置代次和诊断策略。

## 后续
用户手动挑选今日重点、项目工作现场、跨内容最近访问、日历、待处理结果收件箱、天气商用接口、多会话聊天历史、播放列表排序、音量和音频标签元数据解析。
