# UI设计

标准宽度：顶部32px工作台标题，下方三列两行，卡片留白16px、间隔12px。第一行今日重点/继续工作/快速收集，第二行天气/音乐/AI入口。高度不足时工作台滚动，列表内容独立滚动。

950px以下两列，600px以下单列。沿用12px提示、14px控件、15px正文和17px标题，以及已提亮的灰阶。无额外装饰动画，不重建编辑中的textarea。

天气采用概况与详情两层：概况卡显示大号温度、天气符号、描述、高低温和四个关键指标；详情取代卡片区，顶部并排显示当前概况与未来 12 小时趋势，下方为可滚动 7 天预报。小时趋势在同一时间轴组合温度曲线、节点、降雨柱、时间和天气符号；7 天温度范围使用全周期共同标尺，今天高亮并标记当前温度位置。天气状态使用可辨识符号和文字，不以背景颜色作为唯一编码。

音乐卡采用紧凑 Now Playing 结构：64px 唱片视觉锚点、曲名、实际来源、当前队列位置、文件名或网络主机，以及配对起止时间的只读进度；底栏组合状态和上一首/播放暂停/下一首控制。播放键是唯一强调动作，本地与网络来源分别使用珊瑚色和青绿色状态色；未解析音频标签和封面时显示中性唱片占位，不合成或伪造专辑图。右上角常驻音乐库与刷新图标，空库另提供“添加音乐”直达设置。设置页使用本地/网络分段控件、音量滑杆、来源配置区和单层曲目列表；本地来源分别提供添加文件和添加文件夹，列表行提供播放与删除动作。

AI 临时对话取代卡片区显示，顶栏明确当前厂商、模型、临时会话和无工作区上下文边界。空态提供规划今天、整理想法、解释问题和拆解行动四个起始建议；消息列最大宽度 820px，用户消息使用紧凑背景，助手回复采用文档式安全 Markdown，模型 HTML 永不执行。输入框固定在底部并自动增高，发送按钮在生成时原位切换为停止；完整回复使用低干扰图标提供复制、重试和保存笔记，停止与失败轮次显示原位状态和恢复动作。

验证标准：首屏主要动作可达、输入无跳动、窄窗口无横向溢出、空/错误状态可理解。新UI截图在dist.noindex/home-workbench-review.png与home-chat-review.png。
