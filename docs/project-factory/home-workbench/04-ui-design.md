# UI设计

标准宽度：顶部32px工作台标题，下方三列两行，卡片留白16px、间隔12px。第一行今日重点/继续工作/快速收集，第二行天气/音乐/AI入口。高度不足时工作台滚动，列表内容独立滚动。

950px以下两列，600px以下单列。沿用12px提示、14px控件、15px正文和17px标题，以及已提亮的灰阶。无额外装饰动画，不重建编辑中的textarea。

天气采用概况与详情两层：概况卡显示大号温度、天气符号、描述、高低温和四个关键指标；详情取代卡片区，顶部并排显示当前概况与未来 12 小时趋势，下方为可滚动 7 天预报。小时趋势在同一时间轴组合温度曲线、节点、降雨柱、时间和天气符号；7 天温度范围使用全周期共同标尺，今天高亮并标记当前温度位置。天气状态使用可辨识符号和文字，不以背景颜色作为唯一编码。

音乐卡采用紧凑 Now Playing 结构：稳定的唱片视觉锚点、曲名、来源类型、文件名或网络主机、只读进度和居中的上一首/播放暂停/下一首图标控制。播放键是唯一强调动作；未解析音频标签和封面时显示中性占位，不合成或伪造专辑图。空库提供“添加音乐”直达设置。设置页使用本地/网络分段控件、音量滑杆、来源配置区和单层曲目列表，列表行提供播放与删除动作。

AI对话取代卡片区显示，消息列表与底部输入分离。用户消息背景区分，回复按纯文本呈现，禁止模型输出HTML执行；完整回复提供复制。

验证标准：首屏主要动作可达、输入无跳动、窄窗口无横向溢出、空/错误状态可理解。新UI截图在dist.noindex/home-workbench-review.png与home-chat-review.png。
